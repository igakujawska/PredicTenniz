# External match data used by model v2

`history-v2.json.gz` is a filtered, compressed representation of ATP match dates, player source IDs, ranks, surfaces and categories. Source/compiler: Jeff Sackmann, tennis_atp; mirror: [Aneeshers/tennis-sackmann-archive](https://github.com/Aneeshers/tennis-sackmann-archive/tree/83733587353df8a41f2fd4f516147d5aa83f5a8d), revision `83733587353df8a41f2fd4f516147d5aa83f5a8d`.

These external data retain [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/). Changes: excluded non-standard competitions and unfinished matches; normalized IDs; added reviewed tournament categories; exported dated events for availability-aware inference. Original file URLs and SHA-256 values are recorded in `form-xgboost-v2.json`. Redistribution must retain attribution and applicable terms.
