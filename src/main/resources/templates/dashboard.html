03

Zapisane drabinki

Wróć do swojego układu par. Prognozę przeliczamy przy otwarciu na dostępnych danych historycznych.

Jeszcze nie wczytano zapisanych turniejów.

Co dzieje się po kliknięciu „Oblicz”?

Przeglądarka wysyła układ par do Spring Boot. Backend pobiera rankingi z PostgreSQL, oblicza szanse pojedynczych meczów i przekazuje je do silnika drabinki.

Wzór bazowy: P(A wygrywa) = √rank(B) / (√rank(A) + √rank(B)). Nie uwzględnia jeszcze nawierzchni, formy, kontuzji ani historii spotkań. Wyniki są ilustracją modelu, a nie potwierdzoną skutecznością przewidywania.

Zapisujemy datę danych i kolejność graczy. Późniejsze uzupełnienie historii rankingów lub wymiana modelu może zmienić przeliczoną prognozę. Import JSON obsługuje pliki wyeksportowane z tego ekranu; rozpoznawanie drabinek ze zdjęć i PDF będzie osobnym etapem.
